# Hi, I'm Eric 👋

**Applied AI and full-stack engineer. Founder and operator.**

I build AI products end to end: real-time voice agents, RAG systems with human-in-the-loop workflows, and developer tools. Everything below is code I run in production for my own businesses, which means it has to actually work, stay cheap, and fail gracefully.

## Featured projects

**[zencub-rag](https://github.com/eatusc/zencub-rag)** ([live demo](https://zencub-rag.vercel.app)) - LangGraph RAG over a jiu-jitsu video library: hybrid retrieval with citations back to the exact clips, persistent checkpointed workflows with human approval and recovery, and a committed eval suite. Next.js, Supabase/pgvector, strict TypeScript with zero `any`.

**[hap-voice](https://github.com/eatusc/hap-voice)** - Self-hosted AI receptionist answering a real business phone line over Twilio Media Streams. Hand-written G.711 codec, energy VAD, and barge-in handling (caller speech aborts in-flight LLM and TTS mid-sentence), with local whisper.cpp STT. Seven production dependencies total.

**[no-slop](https://github.com/eatusc/no-slop)** - Local-first AI writing detector and cleanup engine. One rule engine ported in parity across JavaScript and Python (Django/DRF), exposed as a web app, REST API, CLI, and MCP server.

**[trading-bb](https://github.com/eatusc/trading-bb)** - Market-research dashboard with a peer-divergence scanner built on leave-one-out robust z-scores (median/MAD) and correlation gating. Next.js, FastAPI, with per-provider API budget guards so free-tier quotas can never be exceeded.

Also on the shelf: a [non-custodial Solana research and paper-trading dashboard](https://github.com/eatusc/meme-ify-public) with layered pre-buy safety gates, and a [Manifest V3 Chrome extension](https://github.com/eatusc/marketplace-helper-public) for marketplace listing management.
